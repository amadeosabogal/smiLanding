# smiLanding

Landing page para **SMI Construcción** — Arquitectura y Construcción de Alta Gama.

## Características

- Diseño moderno, elegante y responsivo para arquitectura y construcción
- Comparador interactivo antes / después (Before & After Slider)
- Imágenes optimizadas en formato WebP de alta fidelidad y bajo peso
- Desarrollado con **React**, **TypeScript** y **Vite**

## Scripts Disponibles

- `npm run dev`: Inicia el servidor de desarrollo local
- `npm run build`: Compila el proyecto con TypeScript y Vite para producción
- `npm run preview`: Previsualiza la versión compilada
- `npm run lint`: Ejecuta el linter (Oxlint)
